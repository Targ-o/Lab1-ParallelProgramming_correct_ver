# задание

Написать программу на языке C/C++ для перемножения двух квадратных матриц.
Исходные данные: файл(ы) содержащие значения исходных матриц.
Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи и др.
Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например на Matlab/Python).

# Описание алгоритма

Первый цикл перебирает строки первой матрицы, второй цикл перебирает столбцы второй матрицы,третий цикл выполняет суммирование произведений соответствующих элементов. После завершения внутренних вычисленийэлемент результирующей матрицы счи
тается вычисленным.

Алгоритм выполняет умножение без использования параллельных вычислений. Все операции производятся последовательно одним потоком выполнения.

Временная сложность алгоритма: O(N³), для вычисления каждого из N² элементов результата выполняется суммирование по N элементам
Объём памяти, необходимый для хранения матриц,: О(N²).

# Организация эксперимента

проведены измерения для семи размеров квадратных матриц: 20 × 20, 200 × 200, 400 × 400, 800 × 800, 1200 × 1200, 1600 × 1600 и 2000 × 2000.

#Вывод
В ходе лабораторной работы была рассмотрена задача умножения двух квадратных матриц и исследована производительность последовательного алгоритма на языке C++.

Были проведены измерения для матриц размером от 20 × 20 до 2000 × 2000. Минимальное измеренное время составило 0,0001949 секунды, а максимальное — 173,7567834 секунды.

Эксперимент показал, что последовательная реализация подходит для небольших задач, однако при обработке больших матриц вычислительные затраты становятся значительными.

Таким образом, поставленная задача реализации умножения квадратных матриц и экспериментального исследования зависимости времени выполнения от размера входных данных была рассмотрена.
